# Stroke File for a painting app called Expresii
# Format: 
# A single character for command, following by parameters separated by space 
# Comments are lines with first character being '#'
# 
# Commands:
# 's' for Stroke Frames that defines the posture of the virtual brush. Format:
# s x y z Tilt-Y Tilt-X Barrel-Rotation Pressure
# Note: x y z are the coordinates of the base of the brush tuft. Tilt-Y Tilt-X Barrel-Rotation are in degrees. Pressure range [0 .. 1]
# Tilt-Y: positive pointing towards North. # Tilt-X: positive pointing towards West.
# Examples:
s  -2.54733  -2.81821   0.03829 -33.00000 -28.00000   0.00000   0.00000 
s  -2.41789  -2.73446  -0.00687 -33.00000 -28.00000   0.00000   0.15000 
s  -2.39505  -2.72684  -0.04299 -33.00000 -28.00000   0.00000   0.26698 
s  -2.38743  -2.72684  -0.07189 -33.00000 -28.00000   0.00000   0.28944 
s  -2.37982  -2.72684  -0.09502 -33.00000 -28.00000   0.00000   0.31473 
s  -2.37220  -2.71923  -0.11351 -33.00000 -28.00000   0.00000   0.35283 
s  -2.35698  -2.71923  -0.12831 -33.00000 -28.00000   0.00000   0.39865 
#
# 'c' for Clearing the page. 
# Examples:
c
#
# 'C' for selecting a Color Profile (a.k.a. preset). Format:
# C profile_index
# Expresii ships several built-in paint color profiles. Selecting one makes
# all following 'l' (Color Loading) commands assign their colors to THAT
# profile. A gradient/tuft is built by: pick a profile with 'C', then load
# its 9 brush-node colors with 'l' (node 0 = brush tip .. node 8 = root).
# Do NOT confuse uppercase 'C' (profile select) with lowercase 'c' above
# (clear page) — they are different commands, and sending 'c' inside a
# color-loading sequence will clear the page instead of selecting a profile.
# Example (select profile 8, then load a warm->white tuft gradient):
C   8.00000 
l 0 229 40 26 
l 1 237 200 6 
l 2 178 179 52 
l 3 114 161 40 
l 4 117 158 42 
l 5 106 152 48 
l 6 80 134 74 
l 7 104 111 184 
l 8 255 255 255 
#
# 'B' for Brush Size. Range [1 .. 7]
Format:   
# B size
# Example:
B   4.00000 
#
# 'w' for Brush Wetness. Range [0.01 .. 1.0]
Format:   
# w wetness
# Sample wetness commands from Wetness Level 12 to Wetness Level 1
w   1.00000 
w   0.65000 
w   0.40000 
w   0.19000 
w   0.15000 
w   0.10000 
w   0.09000 
w   0.08000 
w   0.06000 
w   0.04000 
w   0.03000 
w   0.01000 
#
# 'l' for Color Loading. Format:   
# l NodeIndex R G B
# where NodeIndex is the node number. R G B are the RGB values of the color at that node.
# (NOTE: the real app uses 3 color values R G B. The originally-documented 4th
#  value A / alpha is not used by the stroke loader — include it at your own risk.)
# Each virtual brush has 9 nodes along its length indexed from 0 to 8, going brush tip to brush root. R,G,B in range of [0 .. 255]
# The 'l' colors are assigned to the Color Profile selected by the most recent 'C' command
# (see 'C' above). Load all 9 nodes to define a tuft gradient; with a hard brush tilt the
# gradient shows across the stroke WIDTH.
# Examples:
l 0 78 150 220 
l 1 143 118 188 
l 2 222 78 149 
l 3 240 68 139 
l 4 225 78 147 
l 5 208 96 158 
l 6 212 142 181 
l 7 245 223 226 
l 8 255 255 255 
#
# 'i' for Brush Scratchiness. Range [0.0 .. 1.0] Format:
i   0.5
